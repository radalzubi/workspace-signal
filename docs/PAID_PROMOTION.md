# Paid promotion

Paid advertising is intentionally disabled and no live ad-creation call exists in
the MVP. Manual spend import allows profit reporting while official API access and
account eligibility are researched for the operating business.

Eligibility requires every condition:

- `ENABLE_PAID_ADS=true`.
- Positive `DAILY_AD_BUDGET`, `MONTHLY_AD_BUDGET`, and
  `MAX_SPEND_PER_CONTENT`.
- Content state is `winner`.
- Minimum organic impressions, CTR, and conversion signals pass.
- Requested spend remains below content, daily, and monthly hard limits.

The application rejects on any failed condition. Default 30-day test policy: no
ads for the first 21 days; then at most $5/day and $15/content for a post with
500+ organic impressions, CTR ≥2.5%, and at least one attributed conversion.
These are test thresholds, not guarantees.

Never purchase followers, likes, comments, saves, views, bot traffic, or engagement
packages. Use only official advertising systems and platform-compliant commercial
content.
